# Audio

Los efectos de seleccion y confirmacion de orden de aldeanos del MVP son procedurales y se generan en el cliente con Web Audio, por lo que no requieren atribucion externa.

Cuando se agreguen voces, foley o efectos grabados:

- Guardar los archivos fuente o exportados en esta carpeta.
- Documentar autor, fuente, licencia y cambios realizados.
- Evitar caricaturizar culturas reales; los sonidos deben ser breves, respetuosos y claros como feedback de RTS.
