# Roadmap Inicial

## Fase 0: Base del Proyecto

Estado: iniciada.

Objetivo:

- Monorepo creado.
- Repositorio GitHub conectado.
- Plan inicial documentado.
- Stack tecnico definido.

## Fase 1: Prototipo Jugable

Objetivo:

Tener una demo donde una unidad pueda seleccionarse y moverse en un mapa desde el navegador.

Incluye:

- Cliente web con Phaser.
- Mapa top-down simple.
- Camara con desplazamiento.
- Unidad seleccionable.
- Movimiento con clic derecho.
- Estado compartido basico entre cliente y servidor.

No incluye:

- Arte final.
- Campana.
- Balance.
- Civilizaciones completas.

## Fase 2: Loop RTS Basico

Objetivo:

Convertir el prototipo en una partida pequena.

Incluye:

- Aldeanos.
- Recoleccion de maiz y madera.
- Centro ceremonial.
- Casas.
- Produccion de unidades.
- Primer edificio militar.
- Una unidad de combate.
- Victoria por destruir el centro enemigo.

## Fase 3: Identidad Visual

Objetivo:

Empezar a dibujar personajes, edificios y escenarios con direccion clara.

Incluye:

- Siluetas de unidades.
- Paleta visual.
- Primer tileset.
- Centro ceremonial maya placeholder.
- Aldeano.
- Guerrero basico.
- Recursos visibles en el mapa.

Esta fase puede empezar en paralelo con la Fase 1, pero como arte conceptual y placeholders, no como produccion final.

## Fase 4: Online 1v1

Objetivo:

Lograr una partida online sencilla entre dos jugadores.

Incluye:

- Lobby simple.
- Creacion de sala.
- Union a sala.
- Sincronizacion de comandos.
- Servidor autoritativo.
- Reconexion basica si es viable.

## Fase 5: Primera Civilizacion Jugable

Objetivo:

Crear una civilizacion completa para MVP.

Recomendacion inicial:

- Maya.

Incluye:

- Bonificaciones.
- Edificios propios.
- 3 a 5 unidades.
- 3 tecnologias.
- Identidad visual inicial.

## Fase 6: Campana

Objetivo:

Crear la primera mini-campana jugable.

Recomendacion:

- No empezar la campana hasta que el loop RTS basico funcione.
- Si podemos empezar antes con guion, misiones y mapas en papel.

Primera mini-campana sugerida:

**Los Senores del Maiz**

Tres misiones:

1. Fundar una ciudad junto a rios y milpas.
2. Defender rutas de comercio de obsidiana.
3. Unificar ciudades aliadas antes de una guerra ritual.

## Respuesta Corta

Empezamos a dibujar **desde ahora**, pero primero como:

- Bocetos de direccion artistica.
- Conceptos de unidades.
- Siluetas.
- Tiles placeholder.
- Edificios principales.

Arte final y campana jugable empiezan despues de tener:

- Una unidad moviendose.
- Recoleccion basica.
- Construccion basica.
- Combate simple.
